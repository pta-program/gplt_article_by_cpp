# L1-006 - 连续因子（20 分）

- **时间限制**: 400 ms
- **内存限制**: 65536 KB
- **代码长度限制**: 16 KB

---

## 题目描述

一个正整数 $$N$$ 的因子中可能存在若干连续的数字。例如 630 可以分解为 3$$\times$$5$$\times$$6$$\times$$7，其中 5、6、7 就是 3 个连续的数字。给定任一正整数 $$N$$，要求编写程序求出最长连续因子的个数，并输出最小的连续因子序列。

### 输入格式:

输入在一行中给出一个正整数 $$N$$（$$1<N<2^{31}$$）。

### 输出格式:

首先在第 1 行输出最长连续因子的个数；然后在第 2 行中按 `因子1*因子2*……*因子k` 的格式输出最小的连续因子序列，其中因子按递增顺序输出，1 不算在内。

### 输入样例:
```in
630
```

### 输出样例:
```out
3
5*6*7
```

## 示例

### 示例 1

**输入:**
```
630
```

**输出:**
```
3
5*6*7
```

## 题目详解

### 一、解题思路

题目要求求出正整数 N 的**最长连续因子序列**，且输出最小的连续因子序列（1 不算因子）。

关键结论：

1. 起始因子只需枚举到 `sqrt(N)`：若 `i > sqrt(N)`，则除 N 自身外 `i` 不可能是 N 的因子；而"N 为质数（找不到任何连续因子）"的情形单独处理。
2. 连续因子序列 `i, i+1, i+2, ...` 的乘积必须能整除 N。代码中用 `temp = N` 依次尝试除以 `j`（j 从 i 开始递增），只要能整除就继续，从而统计以 `i` 开头的最长连续长度 `current_len`。
3. 用 `max_len` 与 `start` 记录全局最长序列；若最终 `max_len == 0`，说明 N 是质数，此时序列就是 N 本身（长度 1，起始为 N）。
4. 输出：第一行长度，第二行用 `*` 连接的连续因子序列。

### 二、代码流程说明

1. 读入整数 `N`。
2. 初始化 `max_len = 0`、`start = 0`。
3. 外层循环 `i` 从 2 到 `sqrt(N)`：
   - 初始化 `current_len = 0`、`temp = N`、`j = i`；
   - `while` 循环：只要 `temp % j == 0`，就执行 `temp /= j;`、`current_len++;`、`j++;`（即连续因子的乘积仍能整除 N，继续尝试下一个连续数）；
   - 若 `current_len > max_len`，更新 `max_len = current_len`、`start = i`。
4. 若 `max_len == 0`（说明 N 为质数，未找到任何连续因子），令 `max_len = 1`、`start = N`。
5. 第一行输出 `max_len`；第二行循环输出 `start` 到 `start + max_len - 1`，相邻因子之间输出 `*`，最后换行。
6. 执行 `return 0` 结束程序。

### 三、代码流程图

```mermaid
flowchart TD
    A([开始]) --> B[读入整数 N]
    B --> C[初始化 max_len = 0, start = 0]
    C --> D[外层循环 i 从 2 到 sqrt(N)]
    D --> E[初始化 current_len = 0, temp = N, j = i]
    E --> F{temp 能被 j 整除?}
    F -- 是 --> G[temp 除以 j, current_len 加 1, j 加 1]
    G --> F
    F -- 否 --> H{current_len 大于 max_len?}
    H -- 是 --> I[更新 max_len 和 start = i]
    H -- 否 --> J{i 已超过 sqrt(N)?}
    I --> J
    J -- 否 --> D
    J -- 是 --> K{max_len 为 0?}
    K -- 是 --> L[N 为质数, 令 max_len = 1, start = N]
    K -- 否 --> M[输出最长连续因子个数 max_len]
    L --> M
    M --> N[输出 start 到 start+max_len-1 的序列并用 * 连接]
    N --> O([结束])
```
