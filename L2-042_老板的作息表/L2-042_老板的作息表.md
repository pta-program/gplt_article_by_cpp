# L2-042 - 老板的作息表（25 分）

- **时间限制**: 200 ms
- **内存限制**: 65536 KB
- **代码长度限制**: 16 KB

---

## 题目描述

![zcy.png](~/f4125c83-7ab2-4e3f-bc52-048a723803ee.png)

新浪微博上有人发了某老板的作息时间表，表示其每天 4:30 就起床了。但立刻有眼尖的网友问：这时间表不完整啊，早上九点到下午一点干啥了？

本题就请你编写程序，检查任意一张时间表，找出其中没写出来的时间段。

### 输入格式:

输入第一行给出一个正整数 $$N$$，为作息表上列出的时间段的个数。随后 $$N$$ 行，每行给出一个时间段，格式为：

```
hh:mm:ss - hh:mm:ss
```
其中 `hh`、`mm`、`ss` 分别是两位数表示的小时、分钟、秒。第一个时间是开始时间，第二个是结束时间。题目保证所有时间都在一天之内（即从 00:00:00 到 23:59:59）；每个区间间隔至少 1 秒；并且任意两个给出的时间区间最多只在一个端点有重合，没有区间重叠的情况。

### 输出格式:

按照时间顺序列出时间表中没有出现的区间，每个区间占一行，格式与输入相同。题目保证至少存在一个区间需要输出。

### 输入样例:
```in
8
13:00:00 - 18:00:00
00:00:00 - 01:00:05
08:00:00 - 09:00:00
07:10:59 - 08:00:00
01:00:05 - 04:30:00
06:30:00 - 07:10:58
05:30:00 - 06:30:00
18:00:00 - 19:00:00
```

### 输出样例:
```out
04:30:00 - 05:30:00
07:10:58 - 07:10:59
09:00:00 - 13:00:00
19:00:00 - 23:59:59
```

## 题目详解

### 一、解题思路

这道题要求找出老板作息表中未列出的空闲时间段。输入给出了 N 条已安排的时间段，需要找出一天中（00:00:00 ~ 23:59:59）未被覆盖的所有区间。

核心算法：
1. 将所有时间转换为秒数（	ime_to_seconds）便于数值比较
2. 按开始时间排序所有时间段
3. 遍历排序后的时间段，找出相邻时间段之间的空隙
4. 处理首尾边界：从 00:00:00 到第一个时间段开始，最后一个时间段结束到 23:59:59

### 二、代码流程说明

1. 读取时间段数 N
2. 读取每个时间段的起止时间，转换为秒数存入 intervals 数组
3. 按开始时间升序排序 intervals
4. 初始化 prev_end = 0（即 00:00:00）
5. 遍历排序后的每个时间段：
   - 若 interval.start > prev_end，输出从 prev_end 到 interval.start 的空闲区间
   - 更新 prev_end = max(prev_end, interval.end)
6. 遍历结束后，若 prev_end < 23:59:59，输出从 prev_end 到 23:59:59 的空闲区间
